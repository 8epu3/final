# Final Project

## Running Project 

---

### 1. Clone the Repository

```bash
git clone git@github.com:8epu3/final.git
cd final
```

---

### 2. Create Virtual Environment


```bash
python -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies


```bash
pip install -r requirements.txt
```

### 4. Running the Project


```bash
docker-compose up
```

---
